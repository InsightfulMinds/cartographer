# skills-shelf
status: live
source: skills/ (133 entries, protected tier) ; index/skills-index.json (the SKILL.md corpus with derived keywords, regenerated by index/skill-corpus-audit.py)
what: The runtime's own tool shelf: skill folders, single-file helpers (write-router.sh,
  repo-map, doc indexers) and a few products' operational scripts. Two LaunchAgents
  execute from inside it (mailer-guard, community-capture), so it is not a pure library.
moves: read on demand by sessions; indexed by index passes; propagated to other boxes by
  hand only (no sync leg carries it).
hits: mailer-guard and community-capture (move a folder, break a LaunchAgent);
  index-router lookups until the corpus is regenerated.
does-not-hit: the session tool's own skills dir in the session-tool home (142 entries) —
  a SEPARATE shelf that the tool loads directly; a skill placed here is not loaded there.
